# Math Quiz Game 🎯

A simple console-based Math Quiz Game built using C++.

## 📌 Project Description

This project is an interactive math quiz game where the player answers randomly generated math questions based on selected difficulty level and operation type.

The game supports multiple rounds and provides a final result based on the player’s performance.

---

## 🚀 Features

* Select number of questions (1 to 10)
* Choose difficulty level:

  * Easy
  * Medium
  * Hard
  * Mix
* Choose operation type:

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Mix
* Random question generation
* Real-time answer checking
* Score tracking (Right / Wrong answers)
* Final result display (Pass / Fail)
* Color feedback for correct and wrong answers
